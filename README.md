# 📇 Cartão de Visitas Digital

Este é um projeto simples e elegante de **Cartão de Visitas Digital** desenvolvido com tecnologias web fundamentais (HTML5, CSS3 e JavaScript). O objetivo é centralizar dados de contato, links importantes e informações profissionais de forma acessível e interativa.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído com as seguintes tecnologias:

- **HTML5**: Estruturação semântica e acessível do conteúdo.
- **CSS3**: Estilização moderna, responsiva e personalizada.
- **JavaScript**: Interatividade e manipulação de dados/comportamentos da página.
